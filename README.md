# CCH Research

Graduate research project on **Compound Cascading Hazards** — copula-based multivariate
hydrologic risk, SPH (DualSPHysics) free-surface modelling, and deep-learning flood prediction.
Application domain: Nepal flood hazards, GLOFs, and hydropower risk.

📖 **Notes are published at <https://Cloakmancer.github.io/CCH_Research/>** — searchable, phone-friendly.

## Layout

| Path | Contents |
|---|---|
| `Claude outputs/` | Research notes, knowledge base, research log. **The source of truth.** |
| `scripts/` | Python: Gumbel copula sampling, tail-dependence estimation, distributions |
| `data/`, `notebooks/`, `outputs/` | Awaiting the first real dataset |
| `tools/` | Site build: `sync_docs.py`, home page, assets, publishing guide |
| `docs/`, `site/` | Generated by the build. Git-ignored — do not edit |

## Publishing

See [`tools/PUBLISHING.md`](tools/PUBLISHING.md). Short version: edit notes in
`Claude outputs/`, then `git push`. The site rebuilds itself via GitHub Actions.

Local preview:

```powershell
pip install -r requirements-docs.txt
python tools/sync_docs.py
python -m mkdocs serve
```

## Environment

## A note on scope

These are study and reference notes on standard published methodology. Unpublished results and
data are deliberately kept out of this repository — see the visibility warning in the
publishing guide.
