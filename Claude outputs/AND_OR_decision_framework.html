Return period selection — failure mode decision tool

Answer the questions below to identify which return period definition is physically correct for your design scenario. Click any example to explore further.

Step 1 — Storage effect
Does the structure involve significant storage that routes or attenuates the flood hydrograph before the failure-critical variable is reached?
Step 2 — Single-variable failure
Can the structure fail if only ONE hazard variable is extreme while the other is near-normal?
Step 3 — Failure response
Is the failure response (e.g. max water level, max force) a continuous function of multiple input variables whose joint distribution governs?
✓ AND return period — physically justified
Failure requires simultaneous exceedance of multiple thresholds. Using OR would be over-conservative; using univariate would miss the joint nature entirely. The AND period gives the correct average inter-arrival time between events where all critical variables co-exceed their thresholds.
ANDLarge-storage reservoir spillway
Overtopping requires both high peak AND large volume — storage attenuates peak-only events
ANDCoastal breakwater / seawall
Run-up and overtopping require both wave height AND wave period above critical thresholds
ANDMasonry/earthen structure — seismic + moisture
Seismic failure probability elevated only when both earthquake intensity AND material degradation from prior rain are simultaneously critical
ANDWater supply reservoir — drought + demand
Supply failure requires both low inflow AND high demand to coincide — either alone is manageable
✓ OR return period — physically correct for most flood structures
Failure can be triggered by ANY of the hazard variables exceeding its threshold. The OR period is shorter than AND, reflecting the higher effective risk. This is the correct framing for most levees, floodwalls, bridge piers, and drainage infrastructure — where overtopping or scour can occur from any one critical variable alone.
ORRiver levee / flood embankment
Overtopping occurs if discharge exceeds capacity regardless of volume — single-variable failure governs
ORBridge pier scour
Scour depth is primarily governed by peak velocity — failure can occur from peak discharge alone without joint volume
ORCoastal drainage outfall — surge + rainfall
Outfall blockage or backwater occurs if surge alone is sufficient — rainfall compound makes it worse but failure is not conditional on both
✓ Kendall return period — use when response is a continuous function of multiple drivers
The response variable (e.g. maximum reservoir water level after routing) is a smooth function of multiple input variables with no single-variable threshold governing. The Kendall period partitions the joint probability space into a unique safe/dangerous region via copula level curves — most appropriate for dam safety and spillway design where the failure response integrates peak, volume, and duration jointly.
KENDALLDam safety — routed water level
Maximum pool elevation after routing is a joint function of peak, volume, and duration — Kendall gives a unique critical level curve
KENDALLGLOF moraine dam — lake volume + outflow peak
Breach and downstream flood severity depend jointly on accumulated lake volume, peak outflow, and downstream channel geometry
